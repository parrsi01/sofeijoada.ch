# Security policy

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** feature in the repository's Security tab to send vulnerability reports privately. Do not disclose suspected vulnerabilities in public issues or pull requests.

Include the affected file or feature, the impact, and concise steps to reproduce. Do not include real credentials or customer data in a report.

## Credential exposure

If a credential is exposed, revoke or rotate it immediately. Removing it from a later commit does not make the exposed credential safe.

## Supported versions

Security fixes are intended for the current default branch. This starter repository does not yet contain a deployed application.
